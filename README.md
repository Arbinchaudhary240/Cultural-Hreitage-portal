# Cultural Heitage Portal ( Sanskriti )


## Overview

Cultural hritage portal (Sanskriti) is a community driven web based portal which is design and developed to document, preserve, and make universally accessible the vanishing identities of the world, covering religions, castes, sub-castes, and ethnic groups along with their traditions and cultures. In this rapid urbanizations world this portal gonna be our "Digital Elder". It also help the researcher who research over any religion or any any vanished identity in near future.

## Mission 

To document each and every traditions and culture of each and every religions, castes and ethinic group preserving it for decades and make accessible for all.

## Features

### 1. Interactive Discovery Dashboard
The dashboard will move away from a standard search bar and toward a visual taxonomy. Using a React-based grid, users can drill down from broad categories to specific identities:

**Taxonomy Layers**: Religion → Ethnic Group/Caste → Sub-caste/Region →    Specific Tradition.

**Community profile**: Each group gets a structured page showing historical background, geographic distribution, key traditions.

### 2. Crowdsourced Living History

**Technical Flow**: When a user contribute, Simply he/she can click Add contribution like add post on facebook and fills form with title, description, if contains add files(audio, vedio, images) and other required information and contribute it like post.
**Metadata Standard**: Esure every item has custom metadata tags (like culture_name and tradition_type) so they are useful to researchers, not just "junk" data.

### 3.The moderation system
To maintain the standards of truth, I will implement a Role-Based Access Control  system that governs all contributions
**General Users**: Can browse, flag content, and submit "draft" contributions.
**The "Ambassador" MVP**: A system where community experts can review and "bless" new submissions.
**Moderation**: A simple "Review Queue" in the Django Admin panel for these ambassadors to approve or flag content.
